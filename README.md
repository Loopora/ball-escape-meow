# Ball Escape Loop

A mobile-friendly, no-dependencies canvas animation. Balls bounce inside a rotating ring. Every ball escaping through the gap is replaced by two new balls, up to the configurable safety limit.

## Run locally
Open `index.html` in your browser.

## Publish with GitHub Pages
1. Create a new public GitHub repository, e.g. `ball-escape-loop`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root (not inside a folder), then commit.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**; select `main` and `/ (root)`, then save.
5. Wait for the Pages deployment and open `https://YOUR-USERNAME.github.io/ball-escape-loop/`.

No backend or API keys are required. The ball limit keeps the animation usable on mobile devices.

## Cat sound
Enable **Meow on ball escape**. A locally generated, original synthetic two-syllable meow plays when a ball escapes and multiplies. This is not a copy of a trending TikTok audio clip.
